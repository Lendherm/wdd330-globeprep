# GlobePrep — Destination & Travel Prep Companion

WDD 330 final project (individual).

Helps Pathway / international students research destination countries and plan basic travel prep notes.

## APIs
- [REST Countries](https://restcountries.com/) (v3.1)
- [Frankfurter](https://www.frankfurter.app/) (Week 6+)

OpenWeatherMap is **not** used.

## Week 5 progress
- Project scaffold (Vite + ES modules)
- `countriesApi.mjs` with fetch + `sessionStorage` cache
- Responsive country card grid
- Debounced live search
- Regional filter pills

## Run locally
```bash
npm install
npm run start
```
